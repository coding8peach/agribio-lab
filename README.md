# 🌱 AgriBio Lab

A full-stack multi-agent system that researches, refines, and evaluates
AI/ML research project ideas in agriculture and biology.

## What It Does

Students provide their interests, skills, available resources, timeline,
and budget. A team of specialized AI agents collaborates to develop
research project recommendations that are scientifically meaningful,
technically feasible, and suitable for hands-on experimentation.

## Tech Stack

- CrewAI — multi-agent orchestration
- OpenAI — language models
- Serper — web research
- FastAPI — backend API
- Pydantic — structured agent outputs
- Next.js / React / TypeScript — frontend
- Tailwind CSS — UI

## Features

- Multi-agent research workflow
- Web-grounded project research
- Structured project evaluation
- Scientific and AI/ML feasibility analysis
- Interactive comparison of three project concepts
- Editable student/project profile
- Markdown export
